# Learner Management System (Frontend)

This is the frontend of the **Learner Management System**, a web application designed to manage student information, track progress, and facilitate learning activities. The frontend is built using **React** and is styled with **Bootstrap** for responsive design. It also includes various features such as form handling with **Formik**, Google reCAPTCHA for security, and toast notifications for user feedback.

## Features

- **User Authentication**: Secure login and registration process, including Google reCAPTCHA for bot prevention.
- **Student Management**: Interface for adding, editing, and viewing student details.
- **Dashboard**: Displays student progress, achievements, and other relevant data.
- **Responsive UI**: Built with Bootstrap for a responsive, mobile-friendly design.
- **Form Handling**: Easy-to-use forms for adding and updating student data, validated with Formik.
- **Notifications**: Real-time feedback via toast notifications using React Hot Toast.

## Technologies Used

- **React**: JavaScript library for building the user interface.
- **React Router DOM**: Enables navigation and routing within the app.
- **Axios**: Promise-based HTTP client used for making API requests.
- **Formik**: A library for managing forms and form validation.
- **React Google reCAPTCHA**: Provides CAPTCHA functionality to prevent bots.
- **React Icons**: Library for using icons in the app.
- **Bootstrap**: Frontend framework for styling and ensuring responsive design.
- **React Hot Toast**: Provides toast notifications for feedback to the user.
